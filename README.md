# Hibe Challenge - Node + TypeScript + Express + Drizzle ORM + sqlite3

✅ Compatible con Node.js 20 en Windows.

## 🚀 Instrucciones de uso

1. Instalar dependencias:
```bash
npm install
```

2. Crear archivo .env:
```bash
cp .env.example .env
```

3. Crear la base de datos y aplicar migraciones:
```bash
npm run migrate
```

4. Iniciar el servidor:
```bash
npm run dev
```

Servidor disponible en: http://localhost:3000

Podés probar los endpoints con el archivo `tests/requests.http`.
